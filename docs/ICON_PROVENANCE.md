# Scriber Icon Provenance

Recorded: 2026-07-20

## Current candidate artwork

The candidate Scriber icon artwork was created specifically for this project from basic SVG geometry at Gafie Garcia's direction, with AI-assisted implementation by OpenAI Codex.

Gaf requested a microphone concept in two forms: a white mark on the same `#000000` background used by the discarded draft, and a black mark on transparency. The new artwork uses an original combination of a rounded microphone outline, three transcription lines, a recording cradle, and a stand. No third-party icon, font, logo, or SVG path is intentionally incorporated.

Files:

- [`../apps/macos/Branding/ScriberIcon-BlackBackground.svg`](../apps/macos/Branding/ScriberIcon-BlackBackground.svg)
- [`../apps/macos/Branding/ScriberIcon-Transparent.svg`](../apps/macos/Branding/ScriberIcon-Transparent.svg)

The artwork is offered under `GPL-3.0-or-later` to the extent that Gafie Garcia holds rights that can be licensed. The separate trademark boundary in [`../COPYRIGHT.md`](../COPYRIGHT.md) continues to apply to the Scriber name and branding.

## Discarded draft

An earlier untracked Icon Composer draft, `Untitled.icon`, passed through several Figma Make and Claude Code iterations. Its upstream artwork source and license could not be established. Its SVG path data was not reused or transformed into the candidate artwork, and the draft must not be committed, distributed, or incorporated into a release.

If the candidate is substantially redesigned later, record the tools, source material, contributors, and license of the replacement here before distribution.
