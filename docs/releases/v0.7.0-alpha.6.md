# Scriber 0.7.0-alpha.6

- Release type: personal-use installation candidate
- Bundle build: `7`
- Platform: Apple silicon, macOS 27 beta

This candidate replaces ad-hoc Release signing with the long-lived local `Scriber Local Code Signing` identity. Rebuilt Release bundles keep the same certificate-based designated requirement even when their bundle build and executable hash change, allowing macOS privacy permissions and login-Keychain authorization to recognize them as the same app.

The identity is stored in the login Keychain and backed up separately as a password-protected `.p12`. Release remains entitlement-free and has no embedded provisioning profile. This local identity is for personal builds only; Developer ID signing and notarization remain separate future distribution work.

The transition from build 6's ad-hoc identity requires one final Microphone and Accessibility grant plus Keychain authorization. This annotated snapshot intentionally locks in the verified implementation while a later rebuilt Release and Launch at Login reboot test remain open acceptance checks.
