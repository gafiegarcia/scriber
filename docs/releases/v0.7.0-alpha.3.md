# Scriber 0.7.0-alpha.3

- Release type: frozen personal-use installation candidate
- Bundle build: `4`
- Platform: Apple silicon, macOS 27 beta

This snapshot changes the API-key backend to the encrypted macOS login Keychain while retaining modern `SecItem` APIs. Its Release configuration is ad-hoc signed, contains no restricted Keychain entitlement or provisioning profile, and is intended to remain at `/Applications/Scriber.app` for daily personal use.

The file-based Keychain is an interim compatibility workaround on Apple's road to deprecation. Scriber does not use plaintext storage, `UserDefaults`, deprecated `SecKeychain*` or `SecAccess` APIs, or custom ACL APIs. The storage policy retains a tested login-first migration path back to Data Protection Keychain after Developer Program signing becomes available.

Create the annotated `v0.7.0-alpha.3` tag only after the installed build passes relaunch, restart, credential persistence, permissions, shortcuts, insertion, history, retry, lifecycle, and Launch at Login acceptance.
