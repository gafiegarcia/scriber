# Scriber 0.7.0-alpha.4

> Superseded without a tag: reboot validation showed that build 5 still opened another unsandboxed app's generic Application Support `default.store`. Build 6 moves Scriber to a dedicated store.

- Release type: personal-use installation candidate
- Bundle build: `5`
- Platform: Apple silicon, macOS 27 beta

This candidate retains the encrypted macOS login Keychain and entitlement-free ad-hoc Release signature from alpha.3. It fixes the Launch at Login startup race by explicitly preparing and reading the existing SwiftData `default.store` before Scriber enables dictation services, retrying only brief store-open failures that can occur while the user session starts.

Existing Dictation history remains in the same Application Support store. No audio is deleted until its transcript has been saved.

Create the annotated `v0.7.0-alpha.4` tag only after the installed build passes Launch at Login, credential persistence, permissions, shortcuts, insertion, history, retry, and lifecycle acceptance.
