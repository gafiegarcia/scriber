# Scriber 0.7.0-alpha.5

- Release type: personal-use installation candidate
- Bundle build: `6`
- Platform: Apple silicon, macOS 27 beta

This candidate fixes the confirmed Launch at Login failure at its storage boundary. Scriber now owns `~/Library/Application Support/Scriber/History.store` instead of opening the generic `default.store`, which on the test Mac belongs to another app and contains an incompatible `APIRequestModel` schema.

Pending `.m4a` recordings that were preserved during earlier store failures are imported as retryable Dictation entries the first time the dedicated store opens. If persistent history cannot open, Scriber blocks new recordings instead of silently using temporary in-memory history.

The encrypted login-Keychain policy and entitlement-free ad-hoc Release signature remain unchanged. A newly rebuilt ad-hoc app may prompt once for access to the existing Keychain item; choosing Always Allow grants that particular build access.

Create the annotated `v0.7.0-alpha.5` tag only after the installed build passes Launch at Login, credential persistence, permissions, shortcuts, insertion, history, retry, and lifecycle acceptance.
