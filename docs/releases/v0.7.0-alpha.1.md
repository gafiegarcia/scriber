# Scriber 0.7.0-alpha.1

- Release type: frozen personal-use source snapshot
- Bundle build: `3`
- Platform: Apple silicon, macOS 27 beta

## Why this snapshot exists

This is the first native Scriber revision that Gaf accepts as reliably usable in his regular personal workflow. It preserves a known-good source state before further feature work or risky insertion changes.

## Highlights

- Native menu-bar dictation with hold and toggle shortcuts, local Dictation history, retryable transcription, and ElevenLabs Scribe v2 integration.
- Automatic insertion with clipboard preservation and copied fallback.
- Successful insertion into ordinary native editors and web-backed editors whose focused control is hidden from Accessibility, including ChatGPT.
- Browser paste confirmation that distinguishes a real editable text/caret mutation from a clipboard read on a page with no focused text box.
- No redundant success pill after confirmed insertion; the inserted text is the confirmation.
- Dedicated Data Protection Keychain storage for the API key, isolated credit-free automated tests, and failed-audio retention for retry.

## Verification

- Swift parser validation and core type-checking pass.
- Property-list validation passes.
- All 43 credit-free Swift package tests pass.
- Unsigned Xcode 27 beta Debug and Release builds pass.
- Live personal-use checks cover successful ChatGPT and regular-app insertion plus copied failure behavior when no browser text box is focused.

## Known boundaries

- The current locally run Apple Development build uses a short-lived Personal Team provisioning profile and may need to be rebuilt. The Git tag and source snapshot do not expire.
- A stable-path `/Applications/Scriber.app` installation and the broader manual acceptance matrix remain open.
- No notarized or supported downloadable binary is attached. Developer ID signing and notarization are future distribution milestones, not measures of source maturity.
- macOS 27 and Xcode 27 are beta dependencies.
